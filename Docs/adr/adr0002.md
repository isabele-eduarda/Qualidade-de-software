# ADR 0002 — Escolha do banco de dados

## Status

Aceita — 2026-10-06

## Contexto

O sistema de gestão de agendamentos e pacientes precisa armazenar informações relacionadas a pacientes, profissionais, usuários e agendamentos, garantindo a integridade e a consistência dos dados.

Além disso, o projeto busca utilizar tecnologias de baixo custo, que facilitem o desenvolvimento e permitam a evolução do sistema.

## Decisão

Utilizar o PostgreSQL como sistema de gerenciamento de banco de dados, considerando sua robustez, seu suporte a relacionamentos e sua compatibilidade com o Django.

## Consequências

* O Django oferece suporte à integração com o PostgreSQL.
* O banco de dados permite utilizar restrições de integridade e transações para manter a consistência das informações.
* A utilização desde o início evita uma futura migração do SQLite para o PostgreSQL.
* É uma tecnologia de código aberto, sem custos de licenciamento.

- Será necessário configurar o PostgreSQL e instalar o driver de conexão apropriado no ambiente de desenvolvimento.
- A hospedagem deverá oferecer suporte ao PostgreSQL e atender aos requisitos de disponibilidade e segurança do sistema.
- Será necessário configurar backups e procedimentos de recuperação dos dados.

## Alternativas consideradas

**SQLite:** oferece configuração simples e é utilizado por padrão em novos projetos Django, sendo adequado para desenvolvimento e aplicações menores. Entretanto, o PostgreSQL foi escolhido por oferecer recursos apropriados para as necessidades de integridade, concorrência e evolução previstas para o sistema.
